# Security policy

Only the latest HSEM Ambilights release is supported with security fixes.

Do not publish Home Assistant access tokens, credentials, serial numbers,
diagnostics containing private entity IDs, or unredacted logs in a public issue.
Use the repository's **Security** tab to submit a private vulnerability report.
If private reporting is unavailable, open a public issue containing no sensitive
details and request a private contact channel.

For a suspected issue that could cause unsafe inverter or battery commands,
enable HSEM Read-Only mode immediately and preserve the relevant diagnostics and
logs. Do not reproduce unsafe hardware behaviour solely to gather more evidence.
